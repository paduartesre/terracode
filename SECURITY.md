# Security / Segurança

## Supported scope

Security reports are welcome for the current Community Edition on `main`. TerraCode is a local single-user application that can modify files and run Terraform and Git with the operating system user's permissions. Keep its interface and API on loopback; it is not a hosted multiuser service.

## Report privately

Email **pedroduarte@terracodeiac.com** with the affected commit or version, operating system, reproduction steps, impact and a minimal sanitized example. Do not publish exploit details in an issue before the maintainer has reviewed them. Never send real cloud credentials, tokens, private keys, Terraform state or customer data.

Reports are handled by the project maintainer on a best-effort basis. There is no guaranteed response deadline or paid bug bounty.

## Português (Brasil)

Relate problemas de segurança da edição comunitária atual em `main` por e-mail para **pedroduarte@terracodeiac.com**. Informe commit ou versão, sistema operacional, passos para reproduzir, impacto e um exemplo mínimo sem dados sensíveis.

Não publique detalhes de exploração em uma issue antes da análise pelo mantenedor. Não envie credenciais, tokens, chaves privadas, state do Terraform ou dados de clientes.

O TerraCode é uma aplicação local para um usuário, com acesso aos arquivos e comandos permitido pelo sistema operacional. Mantenha interface e API em loopback. Os relatos são tratados conforme a disponibilidade do mantenedor, sem prazo garantido nem recompensa financeira.
